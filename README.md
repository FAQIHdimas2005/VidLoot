## 🌟 Overview

**VidLoot** is a modern, high-performance web platform designed to extract and download high-definition media from the world's most popular social networks without any watermarks:
- 🎵 **TikTok:** Clean HD MP4 without watermark + direct MP3 audio.
- 📸 **Instagram:** Reels, Posts, and Videos with high-res thumbnails.
- 🔴 **YouTube:** Shorts and standard videos in 1080p Full HD, 720p HD, 360p, and high-quality MP3 audio.
- 🐦 **X (Twitter):** Highest available bitrate video extraction.
- 👥 **Facebook:** Public clips, reels, and videos with automatic RFC 6266 naming.
- 🎨 **DeviantArt:** Original full-resolution artworks, illustrations, wallpapers, and animation videos without login.

---

## 🚀 Key Features

* **100% Cloud Serverless:** Zero local binary dependency (`yt-dlp` / `ffmpeg` executed in pure cloud scrapers for maximum Vercel compatibility).
* **Anti-CORS & Anti-Black Screen Stream Proxy:** Custom streaming pipeline with chunk piping, RFC 6266 `Content-Disposition: attachment` headers, and resume support for download managers (IDM, ADM).
* **Engineered for SEO:** Dynamic `sitemap.xml`, automated `robots.txt`, OpenGraph cards, Twitter cards, and registered on Google Search Console.
* **Integrated Monetization:** Verified on Monetag with MultiTag and Direct Link rewarded countdown modal.
* **Mobile-First Responsive Design:** Built with Tailwind CSS, Lucide icons, and modern glassmorphism.

## ⚡ Quick Start

### 1. Clone the repository
```bash
git clone https://github.com/FAQIHdimas2005/VidLoot.git
cd VidLoot
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start local development server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 4. Build for production
```bash
npm run build
npm run start
```
